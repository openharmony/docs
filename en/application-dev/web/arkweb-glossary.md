## A

### ArkUI Gestures

ArkUI gestures received by the Web component as a generic component. They act on the Web component itself rather than the web page.

### ArkWeb

ArkWeb provides the Web component for displaying web page content in an app.

### ArkWeb Gestures

The ArkWeb component receives gestures automatically generated from touch events and applies them to the web page.

### Adaptive Page Content Layout

A layout mode in which the Web component size adapts to the page content.

### Async Render Mode

A rendering mode in which the Web component is independently composited as a graphics surface node.

## B

### Black Screen

A problem where web page content cannot be displayed normally and appears black.

### Breakpad

A crash information processing project whose source code is used to compile the minidump_stackwalk tool.

## C

### Canvas

An ArkUI component for custom drawing that supports same-layer rendering.

### Canvas Node

A graphics canvas node whose Web rendering follows system compositing.

### Color Scheme

A declaration of the color scheme supported by a web page.

### CORS Policy

A cross-origin resource sharing policy that controls the security mechanism for cross-origin requests.

### Crashpad

A process crash information processing tool provided by the Chromium kernel, used to record process crash information.

## D

### DOMContentLoaded

An event triggered after the HTML document is fully loaded and parsed.

### Dark Color Scheme

A dark color scheme suitable for low-light environments.

### Data Detector

Automatically identifies phone numbers, URLs, and other information in a page and provides interactive operations.

### Developer Tools (DevTools)

A toolset for debugging frontend pages and monitoring web errors.

### Display Subsystem (DSS)

A system responsible for display compositing as a system component.

### Drag and Drop

The operation of dragging an element from one position to another and dropping it.

### Dynamic Component

A component created through `NodeController` and `BuilderNode` that can be dynamically mounted and removed.

### Dump File

A crash dump file, a binary file that records process crash information, with the .dmp extension.

## F

### File Descriptor

A file identifier used to pass PDF file information.

### Fit Content

A Web layout mode that enables Web content to automatically adapt to the container size while maintaining the correct display ratio.

### Flash Screen

A display anomaly in which page content flickers or switches rapidly.

### Focus Chain

The path along which focus moves between components in an app.

### Force Dark Mode

A mode that forcibly converts web page elements to a dark style.

### FrameNode

A frame node, a basic node type in ArkUI used to build a node tree.

## G

### Gesture

An interactive action performed by the user by touching the screen, such as tap, long press, and swipe. The Web component supports handling of multiple gesture events.

### Gesture Blocking

Blocks gesture events of the Web component.

### Gesture Conflict Handling

Handling of conflicts between ArkUI gestures and ArkWeb gestures.

### Gesture Recognition

Recognizes gestures generated by user touchscreen interactions.

## H

### HarmonyOS Ability Package (HAP)

A deployment unit that contains app code, resources, and configuration files.

### Hole Area

The cutout area on the screen for the camera or sensor.

## I

### Immersive Effect

An effect in which the UI extends into the non-safe area to maximize screen utilization.

### Irregular Screen

A screen with a special shape, such as a notch screen or a punch-hole screen.

## J

### JSBridge

A JavaScript bridge that enables JavaScript interaction between an app and a web page.

## L

### Light Color Scheme

A light color scheme suitable for normal lighting environments.

### Local PDF Document

A PDF document stored in the local resource directory of an app.

## M

### Media Playback Hosting

Media playback of the Web component is hosted by the app side.

### Mixed Content Policy

A policy for controlling the mechanism of mixed HTTP and HTTPS content.

## N

### Named Destination

A predefined target location in a PDF document that can be used to navigate directly to a specified position.

### NativeEmbedStatus

The same-layer embedding status, which is the lifecycle status type of the same-layer rendering tag.

### NavDestination

A navigation destination component used for page navigation. It is part of the Navigation route.

### Navigation

A navigation component used to manage page navigation and routing.

### Navigation Bar

A UI area at the bottom of the system used for navigation interactions.

### Network Hosting

Network requests of the Web component are hosted by the app side.

### Network PDF Document

A PDF document accessed through a network URL.

### NodeRenderType

Node rendering type. A type enum that defines how a node is rendered.

### Notch Screen

A special-shaped screen with a camera notch at the top.

## P

### PDF Document in Application Sandbox

A PDF document stored in the application sandbox directory.

### Page Flickering

A brief visual flickering phenomenon that occurs during page loading or navigation.

### Pre-render Web Page

In the scenario where a web page is started or navigated, a Web component is created in the background in advance to load data and complete rendering, thereby enabling fast display.

### Pre-start Render Process

Before entering a Web page, create an empty Web component in advance to start the Web render process, preparing for subsequent use.

### Print Adapter

A component used to render web page content and generate PDF file information.

## R

### Render Mode

The rendering method of Web component content.

### Render Process Start Failed

A state in which the render process fails to start successfully.

### RenderMode

A rendering mode type, a type enum that defines the rendering method of the Web component.

### RenderProcessMode

The render process mode type, a type enum that defines how the Web render process runs.

### Resource Protocol

A protocol for accessing app resources, used to access resource files within an app.

### Responsive Layout

A page layout technology that enables Web pages to automatically adjust their layout based on different device screen sizes.

### registerNativeEmbedRule

The interface for registering same-layer embedding rules, used to specify the tag type for same-layer rendering.

## S

### Safe Area

The area on the screen that is not obscured by device hardware or system UI.

### SafeAreaEdge

A safe area edge type. A type enum that defines the extension direction of the safe area.

### SafeAreaType

Safe area type, a type enum that defines the safe area extension type.

### Same-layer Component

An ArkUI component that is rendered synchronously with H5 tags.

### Same-layer Render

A technology that renders H5 tags and ArkUI components synchronously.

### Same-layer Tag

An embed or object tag used for same-layer rendering in an H5 page.

### Scheme Handler

A scheme handler used to intercept and process network requests of specific protocols initiated by the Web component.

### Screen Distortion

A problem where page content is displayed in a disordered manner or with abnormal colors.

### Search Bar

A UI component used to enter search keywords.

### Status Bar

The area at the top of a device that displays the system status. Tap it to return to the top of the page.

### Subsystem

A functional module division unit in the OpenHarmony architecture.

### Surface Node

A graphics surface node used for independent compositing.

### Sync Render Mode

A rendering mode in which the Web component, as a graphics canvas node, follows system compositing.

### System Navigation Bar

The bottom navigation bar UI area provided by the system.

### System Unsafe Area

System UI areas such as the status bar, punch-hole area, and navigation bar.

### SYNC_RENDER

A sync render mode in which the Web component acts as a graphics canvas node and follows system compositing for rendering.

### Soft Keyboard Avoidance

The layout adjustment made by a web page to avoid the display area of the soft keyboard.

## T

### TextInput

An ArkUI component for text input that supports same-layer rendering.

### Texture Export Mode

A mode in which component content is rendered through texture export.

### Theme Mode

The light or dark display theme provided by the system.

### Touch Event

An interaction event triggered when the user touches the screen.

## U

### Unsafe Area

An area on the screen that is obscured by device hardware or system UI.

### UserAgent

A string that identifies the browser type and version.

## V

### ViewTree

The view tree, which is the target component tree where components are mounted.

### Visual Flickering

A visual flickering phenomenon that occurs when page content is switched.

## W

### Web Dark Mode

Defines the type enum of the dark mode state of the Web component.

### Web Layout Mode

Defines the type enum of the layout mode of the Web component.

### Web Page Content Height

The height of the actual page content.

### Web Render Process

A process used to render web content.

### WebResourceResponse

A web resource response class used to construct the data structure of a custom resource response.

### Waterfall Page

A type of web page that uses a waterfall layout.

### WebNativeMessagingExtensionAbility

A Web native messaging extension capability, a component that provides background services for browser extensions.

### White Screen

A problem where web page content cannot be displayed normally and appears blank.

## X

### XComponent

An ArkUI component used for custom rendering. It supports same-layer rendering.
