Localization refers to displaying regional elements such as language, region, script, time zone, calendar, and date in accordance with local language conventions.

Localization can be implemented in the following ways:

1. [Localized names](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DisplayNames): Use the **Intl.DisplayNames** API to localize the display of languages, regions, scripts, currencies, calendars, and time fields (such as year, month, and day).

2. [Localized language and region names](i18n-language-region-display.md): Use the **i18n.System.getDisplayLanguage** and **i18n.System.getDisplayCountry** APIs to localize the display of languages and regions.
