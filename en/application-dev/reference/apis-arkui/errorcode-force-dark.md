## 106205 Color Inversion Capability Configuration Error

**Error Message**

Force dark config is invalid.

**Description**

This error code is reported when the color inversion capability configuration is invalid.

**Possible Causes**

The input parameter passed for the color inversion capability is invalid.

**Solution**

Correct the input parameter to meet the color inversion capability's requirements.
