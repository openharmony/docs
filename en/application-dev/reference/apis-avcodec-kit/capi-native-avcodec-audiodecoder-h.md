### OH_AudioDecoder_PushInputData()

```c
OH_AVErrCode OH_AudioDecoder_PushInputData(OH_AVCodec *codec, uint32_t index, OH_AVCodecBufferAttr attr)
```

**Description**

Notifies the audio decoder that the input data has been filled into the buffer corresponding to the specified index.<br>The [OH_AVCodecOnNeedInputData](capi-native-avcodec-base-h.md#oh_avcodeconneedinputdata) callback reports the available input buffers and the corresponding index values. Once a buffer with the specified index is submitted to the audio decoder, this buffer cannot be accessed again until the [OH_AVCodecOnNeedInputData](capi-native-avcodec-base-h.md#oh_avcodeconneedinputdata) callback is received again with the same index.<br>In addition, for some decoders, specific configuration parameters need to be input to the decoder at the beginning to initialize the decoding process.

**System capability:** SystemCapability.Multimedia.Media.AudioDecoder

**Since**: 9

**Deprecated from**: 11

**Substitutes:** [OH_AudioCodec_PushInputBuffer](capi-native-avcodec-audiocodec-h.md#oh_audiocodec_pushinputbuffer)

**Parameters**

| Name | Description |
| -- | -- |
| [OH_AVCodec](capi-codecbase-oh-avcodec.md) *codec | Pointer to the OH_AVCodec instance. |
| uint32_t index | Index of the input buffer. |
| [OH_AVCodecBufferAttr](capi-core-oh-avcodecbufferattr.md) attr | Describes the information about the data contained in the buffer. |

**Returns**

| Type | Description |
| -- | -- |
