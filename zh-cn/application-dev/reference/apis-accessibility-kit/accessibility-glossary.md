## A

### Accessibility event; 无障碍事件

系统无障碍服务在用户操作或界面变化时生成的事件，通过事件类型标识类别（包括无障碍事件类型、窗口变化类型、触摸浏览事件类型、手势事件类型、页面更新类型），分发给已注册且匹配事件类型的辅助扩展进行响应。

### Accessibility extension; 辅助扩展

基于ExtensionAbility框架的扩展能力类型，专门用于实现无障碍辅助功能。开发者可在其中处理无障碍事件和按键事件，并通过上下文环境查询节点信息、注入手势等。亦称辅助应用。

### Accessibility focus; 无障碍焦点

无障碍服务管理的焦点状态，用于标识当前被辅助功能聚焦的界面元素。与输入焦点不同，是辅助功能（如屏幕朗读）读取或操作界面元素的起点。

### Accessibility Kit; 无障碍服务

OpenHarmony提供的无障碍开发套件，包含辅助功能管理、辅助功能扩展能力、辅助功能扩展上下文、手势路径与触摸点等模块，用于支持开发者构建无障碍辅助应用，帮助视障、听障等用户更好地使用设备。

### Accessibility node element; 无障碍节点元素

UI界面上可被无障碍服务访问和操作的组件（如按钮、文本输入框等），构成无障碍节点树。辅助扩展通过查询节点元素获取界面信息并执行无障碍操作。

### Accessibility virtual node; 无障碍虚拟节点

由辅助扩展应用向无障碍节点树中新增的虚拟节点，用于表示自定义UI元素或补充已有节点的属性信息，使无障碍服务能够访问和操作原本不在系统节点树中的内容。

### Animation reduction; 减弱动效

无障碍辅助模式之一，开启后系统减弱或简化界面动画效果，用于帮助对动效敏感的用户（如前庭功能紊乱者）减轻不适感。

### Auto-broadcasting; 主动播报

应用通过无障碍服务主动向用户播报内容的能力，无需用户手动导航触发。区别于被动响应界面变化的播报，用于在关键业务时刻（如操作完成、状态变更）主动通知用户。

### Auto-focusing; 主动聚焦

应用通过无障碍服务主动将无障碍焦点聚焦到指定元素上的能力，区别于用户手动导航聚焦。用于引导用户关注特定界面元素。


## C

### Color inversion; 颜色反转

无障碍辅助功能之一，开启后系统反转屏幕显示颜色，用于帮助特定视觉障碍用户在反色模式下更舒适地阅读界面内容。


## D

### Daltonization; 色彩校正

无障碍辅助功能之一，通过为不同类型的色弱（红色弱、绿色弱、蓝色弱）应用对应的颜色滤镜校正屏幕显示颜色，帮助色弱用户辨识颜色信息。

### Default focus; 默认焦点

窗口打开时无障碍服务优先聚焦的元素。应用可自定义默认焦点元素ID列表，帮助无障碍服务在界面加载后快速定位到最关键的元素，提升特殊需求用户的交互效率。


## F

### Flash alerts; 闪烁提醒

无障碍辅助模式之一，开启后系统通过屏幕闪烁或闪光灯闪烁提醒用户闹钟、通知、来电等事件，用于帮助听障用户感知声音提醒。


## G

### Gesture injection; 手势注入

辅助扩展应用模拟用户触摸手势（如点击、滑动等）执行触摸交互的能力，用于辅助功能应用替用户完成界面操作。


## H

### High-contrast text; 高对比度文字

无障碍辅助功能之一，开启后系统以更高的对比度渲染文字，增强文字与背景之间的视觉差异，用于帮助低视力用户更清晰地阅读文字。


## M

### Magnification; 放大效果

无障碍辅助功能之一，开启后放大屏幕显示内容，依赖放大手势功能。用于帮助低视力用户放大查看界面局部内容。

### Mono audio; 单声道音频

无障碍辅助模式之一，开启后将左右声道的音频合并为单声道输出，用于帮助单耳听力障碍用户获取完整的音频信息。


## S

### Screen reader; 屏幕朗读

无障碍辅助模式之一，开启后系统将界面内容通过语音朗读给用户，是视障用户操作设备的主要交互方式。通常与触摸浏览模式配合使用。

### Senior mode; 长辈模式

面向老年用户的关怀模式，开启后简化界面交互以适应老年用户的使用习惯。可分别在系统级别和应用级别设置，系统关怀模式通过config模块管理，应用自身长辈模式通过应用接口管理。


## T

### Touch guide; 触摸浏览

无障碍辅助功能中的交互模式，用户在该模式下通过触摸探索界面元素而非直接激活，系统会朗读当前触摸位置的元素信息。是屏幕朗读功能的配套交互方式。

### Touch mode; 触摸模式

触摸浏览功能下的操作模式，分为单击操作模式（触摸即响应）和双击操作模式（需双击确认操作），用于根据用户习惯调整触摸浏览的交互响应方式。
