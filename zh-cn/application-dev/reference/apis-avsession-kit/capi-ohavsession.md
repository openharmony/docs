## 概述

提供媒体会话模块C接口定义。

开发者可使用OHAVSession，作为媒体会话提供方接入AVSession服务。开发指南及样例可参考[媒体会话提供方](../../media/avsession/using-ohavsession-developer.md)。

**系统能力：** SystemCapability.Multimedia.AVSession.Core

**起始版本：** 13

## 文件汇总

| 名称 | 描述 |

| [native_avmetadata.h](capi-native-avmetadata-h.md) | 提供媒体元数据的定义。 |
| [native_avsession.h](capi-native-avsession-h.md) | 提供媒体会话定义，用于设置元数据和播放状态信息。 |
