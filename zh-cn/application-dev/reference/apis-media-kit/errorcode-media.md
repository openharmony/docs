## 5400101 内存分配失败

**错误信息**

No memory.

**错误描述**

分配内存失败。

**可能原因**

1. 实例数量超过16个。
2. new或者malloc流程失败导致空指针。

**处理步骤**

销毁当前实例，并重新创建，如果重新创建失败，则停止相关操作。

## 5400102 当前状态不支持此操作

**错误信息**

Operation not allowed.

**错误描述**

当前操作不允许。

**可能原因**

1. 当前状态不支持此操作。
2. 此应用录屏当前实例数量超过2个或此设备创建录屏实例数超过16个。

**处理步骤**

1. 先确认当前状态是否支持此操作，再把实例切换到正确状态进行正确操作。
2. 释放所有已经创建的实例。

### 触发场景1：更换资源播放失败

**可能原因**

1. 播放器当前处于非idle状态（如prepared、playing、paused、completed、stopped等），直接设置新的播放资源（url/fdSrc/dataSrc）导致操作不允许。AVPlayer要求更换资源时必须先将播放器重置到idle状态。
2. 在仅调用stop()方法后未重置到idle状态即尝试设置新的播放资源。stop()只会将播放器切换到stopped状态，并不会回到idle状态，需调用reset()方法才能回到idle状态。
3. 播放器状态机流转不正确，未按照正确的状态转换的顺序操作，跳过了必要的状态转换步骤。

**处理步骤**

1. 确认当前播放器状态，更换播放资源前必须先调用`avPlayer.reset()`将播放器恢复到idle状态，而非仅调用`avPlayer.stop()`。当stop()切换到stopped状态时，reset()才会回到idle状态。
2. 在idle状态下设置新的播放资源（url/fdSrc/dataSrc），设置成功后会自动切换到initialized状态。
3. 按照正确的状态流转顺序操作：idle→initialized→prepared→playing，避免跳过状态或逆向操作。
4. 如果多次更换资源仍报错，建议调用`avPlayer.release()`销毁当前实例，重新创建AVPlayer实例后再设置资源。

### 触发场景2：文件播放失败

**可能原因**

1. 播放的媒体文件结尾包含不符合格式的数据或尾部信息已损坏的文件，导致解封装器在解析到文件末尾时触发状态异常，进而产生操作不允许错误。
2. 媒体文件封装格式不规范，如MP4文件的moov box位置异常（moov位于文件尾部）、mdat box数据不完整或解封装器在解析过程中状态出错。
3. 播放器在文件解析异常状态下被调用了播控操作（如seek、pause、play等），当前状态不支持该操作。

例如：（1）未设置源调用play 错误信息：errorCode 5400102 The current state is idle. Play operation only supports prepared/paused/completed.

（2）Initialized 状态调用play 错误信息：errorCode 5400102 The current state is initialized. Play operation only supports prepared/paused/completed.

（3）Playing 状态调用reset 后play() 错误信息：errorCode 5400102 the current state is idle. Play operation only supports prepared/paused/completed.

（4）Initialized 状态调用seek() 错误信息：errorCode 5400102, errorMsg Operate Not Permit: The current state is initialized, seek operation only support prepared/playing/paused/completed state.

**处理步骤**

1. 检查媒体文件是否完整，文件结尾遇到非标准数据时可能触发状态错误，建议使用其他播放工具验证文件是否可正常播放。
2. 确认媒体文件的封装格式是否标准，不规范的封装可能导致解封装器状态异常，进而触发操作不允许错误。
3. 如果播放器因文件异常进入error状态，调用`avPlayer.reset()`重置播放器到idle状态，更换正常的媒体文件后重新播放。
4. 如果reset后仍处于error状态，建议直接调用`avPlayer.release()`释放资源，重新创建AVPlayer实例。

## 5400103 出现IO错误

**错误信息**

I/O error.

**错误描述**

出现IO错误。

**可能原因**

媒体与其他模块的数据交互发生问题（图形、音频、网络、HDI、相机）。

**处理步骤**

确认网络是否通畅，并销毁当前实例，并重新创建，如果重新创建失败，则停止相关操作。

### 触发场景1：音频渲染器启动失败

**错误信息**

I/O error: audio render failed.

**错误描述**

音频渲染器启动失败。

**可能原因**

1. 设备音频输出通道被其他应用独占（如正在通话、录音等），导致音频渲染器无法获取输出资源。
2. 音频流参数配置（采样率、声道数、编码格式）与源文件不匹配或超出设备支持范围，渲染器无法按指定参数启动。
3. 系统音频服务异常或未正常初始化，音频HDI（Hardware Device Interface）驱动加载失败，导致渲染器创建失败。

**处理步骤**

1. 检查设备音频输出设备（扬声器、耳机）是否正常连接，确认未处于静音或音量为0的状态。
2. 检查是否有其他应用正在独占音频输出通道（如通话、录音等），如有则等待其释放后再播放。
3. 检查音频流的参数配置（采样率、声道数、编码格式）是否与源文件匹配，不匹配的参数会导致渲染器启动失败。
4. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
5. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，等待系统音频服务恢复后再重试。

### 触发场景2：视频解码器启动/解码失败

**错误信息**

I/O error: video decode failed.

**错误描述**

视频解码器启动/解码失败。

**可能原因**

1. 视频资源的编码格式（如H.264、H.265、VP8等）不被当前设备解码器支持，或视频流的profile/level超出硬件解码能力范围。
2. 视频码流数据不完整或损坏，网络不稳定导致关键帧数据缺失，解码器无法正常启动或持续解码。
例如：HLS返回HTML分片（content-Type:text/html）错误信息：errorCode 5400103, errorMsg IO Error: DEM_PARSE_ERR-unkown error, media data source error unknow, video/avc
3. 解码器状态异常，在错误状态下调用了start/reset等操作，或底层HDI（Hardware Device Interface）驱动资源不足/异常导致解码失败。

**处理步骤**

1. 检查视频资源的编码格式（如H.264、H.265、VP8等）是否为系统支持的解码格式。
2. 检查视频流的参数（分辨率、帧率、profile/level）是否超出硬件解码器的支持范围，超出时考虑使用软件解码或降低码流规格。
3. 检查是否在解码器处于错误状态时调用了start/reset等方法，确保按照正确的状态流转顺序[使用AVPlayer播放视频(ArkTS)](../../media/media/video-playback.md)。
4. 确认网络是否通畅，网络不稳定可能导致码流数据不完整，进而引发解码失败。
5. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
6. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，排查是否为底层HDI（Hardware Device Interface）驱动异常。

### 触发场景3：视频解码器初始化失败

**错误信息**

I/O error: video mimeType Decode create failed.

**错误描述**

视频解码器初始化失败。

**可能原因**

1. 视频资源的mimeType（如video/avc、video/hevc等）不被当前设备支持，无法创建对应的解码器实例。
2. 视频资源的封装格式不标准或文件有损坏，导致解封装器无法正确识别mimeType，解码器创建失败。
3. 系统可用资源不足（如可用内存不足或图形处理器资源被占满），解码器插件无法正常加载或初始化所需资源分配失败。

**处理步骤**

1. 确认视频资源的mimeType（如video/avc、video/hevc等）是否为设备支持的格式。
2. 检查视频资源的封装格式是否正确，不标准或损坏的封装可能导致mimeType解析异常，进而无法创建对应的解码器实例。
3. 检查是否有足够的系统资源（内存、GPU）供解码器初始化使用，内存不足时解码器创建可能失败。
4. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
5. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，排查底层解码器插件加载是否正常。

### 触发场景4：文件打开失败

**错误信息**

I/O error: open file failed.

**错误描述**

文件打开失败。

**可能原因**

1. 文件路径错误或文件不存在，本地路径格式不正确或沙箱路径无效，网络URL无法访问。
2. 应用未获取必要的文件访问权限（如ohos.permission.READ_MEDIA等），导致系统拒绝文件打开请求。
3. 文件被其他进程独占锁定或正在被写入，存在并发访问冲突，导致文件打开失败。
4. 文件本身损坏或格式不规范，解封装器无法正确解析文件头部信息。
5. 网络不通畅或HTTP服务端异常（404、403、500等），导致网络文件无法正常打开。

**处理步骤**

1. 确认文件路径是否正确，检查文件是否存在且路径格式无误（本地路径以沙箱路径开头，网络路径以`http://`或`https://`开头）。
2. 检查应用是否已获取文件访问权限，对于本地文件需确认是否申请了ohos.permission.READ_MEDIA或其他必要的文件读写权限。
3. 确认文件是否被其他进程占用或锁定，若文件正在被写入或被其他应用独占访问，可能导致打开失败。
4. 检查文件是否损坏，建议用其他播放器或工具打开同一文件，确认文件本身是否可正常读取。
5. 如为网络文件，确认网络是否通畅，检查HTTP请求是否返回了正确的响应状态码（如200等），排除网络超时或服务端错误。
6. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
7. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，排查是否为底层文件系统或网络模块异常。

### 触发场景5：文件读写失败

**错误信息**

I/O error: file access failed.

**错误描述**

文件读写失败。

**可能原因**

1. 应用缺少文件读写权限（如ohos.permission.READ_MEDIA、ohos.permission.WRITE_MEDIA），系统拒绝读写请求。
2. 设备存储空间不足，磁盘满或接近满时读写操作无法正常完成。
3. 文件在读写过程中被其他进程修改或删除，并发访问导致数据不一致或读写冲突。
4. 文件损坏或不完整，数据校验失败后读写操作中断。
5. 网络流文件的网络连接中断，数据传输失败导致读取报错。

**处理步骤**

1. 确认文件访问权限是否已正确授予，检查应用是否申请了文件读写相关权限（如ohos.permission.READ_MEDIA、ohos.permission.WRITE_MEDIA）。
2. 检查文件存储空间是否充足，磁盘空间不足可能导致读写操作失败。
3. 确认文件是否在读写过程中被其他进程修改或删除，并发访问可能导致文件内容不一致或读写冲突。
4. 检查文件是否损坏，建议重新下载或恢复文件后再进行播放。
5. 如为网络流文件，确认网络是否通畅，网络中断可能导致数据读取失败。
6. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
7. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，排查底层文件系统或存储模块是否异常。

### 触发场景6：HTTP数据源IO错误

**错误信息**

I/O error: data source io error.

**错误描述**

HTTP数据源I/O（Input/Output）错误。

**可能原因**

1. 网络连接异常（Wi-Fi断开、蜂窝信号弱等），设备无法正常访问HTTP资源。
2. HTTP服务端返回错误状态码（如404资源不存在），数据源无法获取有效数据。
3. 媒体资源URL无效或已过期，服务端资源不可达。
4. 网络波动导致数据下载中断，TCP连接断开或数据包丢失。
5. HTTP请求超时配置过短，弱网环境下频繁触发超时中断。

**处理步骤**

1. 确认网络是否通畅，检查设备网络连接状态（Wi-Fi/蜂窝），确保能正常访问HTTP资源。
2. 检查HTTP请求的响应状态码，排除服务端错误（如404资源不存在等）。
3. 确认媒体资源URL是否正确且可访问，尝试在浏览器或其他网络工具中直接访问该URL，验证资源是否可用。
4. 检查是否因网络波动导致数据下载中断，如有条件可尝试切换网络环境（如从蜂窝切换到Wi-Fi）后重新播放。
5. 确认HTTP请求的超时配置是否合理，超时时间过短可能在弱网环境下频繁触发IO错误。
6. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
7. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，排查是否为网络模块或HTTP协议栈异常。

### 触发场景7：解封装缓存满

**错误信息**

I/O error: demuxer buffer malloc failed.

**错误描述**

解封装缓存满。

**可能原因**

1. 设备可用内存不足，解封装缓存分配失败，无法为码流数据分配足够的缓冲区空间。
2. 媒体资源码率过高，高码率数据需要更大的缓存空间，超出解封装预设的缓存容量上限。
3. 多个播放器实例并发运行，各实例的解封装缓存同时占用系统内存，总缓存需求超出可用内存。
4. 网络带宽不足导致数据积压，下载速度跟不上消费速度，缓存持续增长直至溢出。

**处理步骤**

1. 检查设备的可用内存是否充足，内存不足可能导致解封装缓存分配失败，清理后台应用释放内存后再尝试播放。
2. 确认媒体资源的码率是否过高，高码率资源需要更大的缓存空间，可尝试播放码率较低的版本。
3. 检查是否因网络带宽不足导致数据下载速度跟不上播放速度，缓存持续积压最终溢出，可尝试在更好的网络环境下播放。
4. 确认是否有多个播放器实例同时运行，多个实例并发占用缓存可能导致总缓存超限，减少并发实例数量后再尝试。
5. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
6. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，排查是否为底层内存管理模块异常。

### 触发场景8：Surface操作失败

**错误信息**

I/O error: get input surface failed.

**错误描述**

Surface操作失败。

**可能原因**

1. 在AVPlayer状态不正确时调用`avPlayer.surfaceId`设置Surface，导致获取input surface请求失败。
2. SurfaceID无效，XComponent或其他Surface提供组件未正确初始化，生成的SurfaceID不可用。
3. Surface的BufferQueue配置异常，消费者（解码器）与生产者（渲染端）连接未正常建立，无法获取input surface。
4. 同一Surface被多个播放器或其他组件同时绑定，资源竞争导致Surface操作失败。
5. 底层图形模块或Surface管理服务异常，Surface相关接口调用返回错误。

**处理步骤**

1. 确认在调用`avPlayer.surfaceId`设置Surface之前，AVPlayer是否处于正确的状态（应为prepared或之前的状态），状态不正确时设置Surface可能失败。
2. 检查传入的SurfaceID是否有效，确保XComponent或其他Surface提供组件已正确初始化并生成了有效的SurfaceID。
3. 确认Surface的消费者（解码器）与生产者（渲染端）连接是否正常。
4. 检查是否有多个组件争抢同一Surface资源，确保同一Surface未被多个播放器或其他组件同时绑定。
5. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
6. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，排查是否为底层图形模块或Surface管理服务异常。

### 触发场景9：未知错误兜底

**错误信息**

I/O error: unknown error.

**错误描述**

未知错误兜底。

**可能原因**

1. 媒体与其他模块的数据交互发生问题（图形、音频、网络、HDI、相机等），某个关联模块内部异常导致不可预知的IO错误。
2. 系统资源紧张（CPU、内存、GPU负载过高），各模块间数据传递时发生超时或丢失。
3. 媒体资源文件不完整或格式不规范，触发了未覆盖到的边界异常。
4. 底层驱动或服务异常，HDI接口调用失败但错误码未被上层正确识别和分类。

**处理步骤**

1. 查看完整日志信息，确认是否有更具体的错误子类型或关联模块的报错（图形、音频、网络、HDI、相机等），优先根据关联模块的报错进行针对性排查。
2. 确认网络是否通畅，部分未知错误可能由网络异常间接引发。
3. 检查设备系统资源（CPU、内存、GPU）是否充足，资源紧张可能导致各模块交互异常。
4. 确认媒体资源文件本身是否完整且格式标准，损坏或不规范的资源文件可能触发各种不可预知的错误。
5. 如果上述排查均未定位到具体原因，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
6. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，将日志反馈给开发团队进行深入排查。

### 触发场景：解封装失败

**错误信息**

unsupport container format type.

**错误描述**

解封装失败。

**可能原因**

1. 媒体资源的封装格式（如MP4、MKV、FLV、TS等）不被系统支持。

例如：播放AV1视频，错误信息为：errorCode 5400106, errorMsg Unsupported Format: VID_DEC_ERR-unsupport interface, unsupport video decoder type, video/av1-

2. 媒体资源文件损坏或不完整，解封装器无法正确识别容器类型。

例如：（1）视频文件损坏（mp4 ftyp 头部正常，缺少moov和媒体数据）错误信息为：errorCode 5400106, errorMsg Unsupported Format: CONTAINER_ERR-unsupport interface, unsupport container 
format type, null-

（2）打开空文件，错误信息为：errorCode 5400106, errorMsg Unsupported Format: CONTAINER_ERR-unsupport interface, unsupport container format type, null-

（3）文本伪装MP4 文件，错误信息为：errorCode 5400106, errorMsg Unsupported Format: CONTAINER_ERR-unsupport interface, unsupport container format type, null-

3. 媒体资源的URL或文件路径错误，导致加载到无效数据。
4. 网络流资源因网络中断导致数据不完整，解封装器缺少关键头部信息而无法识别格式。
5. 资源包含DRM保护或其他加密机制，无法被标准的解封装器正常解析。

**处理步骤**

1. 确认媒体资源的封装格式（如MP4、MKV、FLV、TS等）是否为系统支持的格式。
2. 检查媒体资源文件是否损坏或不完整，不规范的封装可能导致解封装器无法正确识别容器类型，可以使用其他播放工具验证文件是否可正常播放。
3. 确认媒体资源的URL或文件路径是否正确，错误的路径可能导致加载到无效数据，进而被解封装器判定为不支持格式。
4. 网络流资源需要确认网络是否通畅，网络中断可能导致数据不完整，解封装器因缺少关键头部信息而无法识别格式。
5. 检查资源是否包含DRM保护或其他加密机制，加密资源可能无法被标准的解封装器正常解析。
6. 如果上述检查均无异常，调用`avPlayer.release()`销毁当前实例，然后重新创建AVPlayer实例并再次尝试播放。
7. 如果重新创建后仍然报错，建议记录详细日志并停止播放操作，排查是否为底层解封装插件加载异常或格式支持范围不足。

**错误信息**

Super resolution not supported.

**错误描述**
