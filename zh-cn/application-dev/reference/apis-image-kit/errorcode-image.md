## 501 无法调用接口

**错误信息**

Resource unavailable.

**错误描述**

无法调用接口。

**可能原因**

图片被跨线程传递，原对象无法调用接口。

**处理步骤**

请检查图片并按指示操作重新解码。

**处理步骤**

不要在PixelMap对象被传递到另一个线程后仍在原线程调用该对象的接口。

**处理步骤**

检查图片数据或更换图片。
